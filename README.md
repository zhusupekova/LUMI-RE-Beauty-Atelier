# LUMIÈRE Beauty Atelier

Статический сайт премиального салона красоты в Бишкеке. Проект показывает услуги, атмосферу бренда, контакты и быстрые действия для записи.

Live demo:
https://zhusupekova.github.io/LUMI-RE-Beauty-Atelier/

## Возможности

- адаптивная главная страница;
- блоки услуг, преимуществ и контактов;
- премиальная визуальная стилистика;
- быстрые CTA для записи;
- Open Graph изображение для красивого превью ссылки.

## Стек

- HTML
- CSS
- JavaScript
- GitHub Pages

## Публикация

Сайт является статическим и публикуется через GitHub Pages с помощью workflow `.github/workflows/pages.yml`.
